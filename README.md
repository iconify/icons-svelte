Browse all icons: [preview Struq Icons on Iconify](https://icon-sets.iconify.design/struq/)

## Installation

```bash
npm install gitlab:iconify-icons/svelte#struq
```

or
```bash
npm install github:iconify/icons-svelte#struq
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/struq/home';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/struq/search';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/struq/settings';
</script>

<SampleIcon style="color: red;" />
```
