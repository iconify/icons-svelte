# @iconify-svelte/material-icon-theme

**Material Icon Theme**

Author: [Material Extensions](https://github.com/material-extensions/vscode-material-icon-theme)

License: [MIT](https://github.com/material-extensions/vscode-material-icon-theme/blob/main/LICENSE)

Browse all icons: [preview Material Icon Theme on Iconify](https://icon-sets.iconify.design/material-icon-theme/)

## Installation

```bash
npm install github:iconify/icons-svelte#material-icon-theme
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/material-icon-theme/zip';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/material-icon-theme/email';
</script>

<SampleIcon height="1em" />
```
