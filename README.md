## Installation

```bash
npm install gitlab:iconify-icons/svelte#ci
```

or
```bash
npm install github:iconify/icons-svelte#ci
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ci/bulb';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ci/house-01';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ci/compass';
</script>

<SampleIcon style="color: red;" />
```
