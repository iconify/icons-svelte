## Installation

```bash
npm install gitlab:iconify-icons/svelte#thesvg
```

or
```bash
npm install github:iconify/icons-svelte#thesvg
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/thesvg/mitsubishi';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/thesvg/tencent';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/thesvg/vuedotjs';
</script>

<SampleIcon style="color: red;" />
```
