## Installation

```bash
npm install gitlab:iconify-icons/svelte#keyline-icons
```

or
```bash
npm install github:iconify/icons-svelte#keyline-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/keyline-icons/arrow-up-narrow-wide-duotone';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/keyline-icons/credit-card-fill';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/keyline-icons/upload';
</script>

<SampleIcon style="color: red;" />
```
