Browse all icons: [preview OpenMoji on Iconify](https://icon-sets.iconify.design/openmoji/)

## Installation

```bash
npm install github:iconify/icons-svelte#openmoji
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/openmoji/bicycle';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/openmoji/bow-and-arrow';
</script>

<SampleIcon height="1em" />
```
