**Flag Icons**

Author: [Panayiotis Lipiridis](https://github.com/lipis/flag-icons)

License: [MIT](https://github.com/lipis/flag-icons/blob/main/LICENSE)

Browse all icons: [preview Flag Icons on Iconify](https://icon-sets.iconify.design/flag/)

## Installation

```bash
npm install gitlab:iconify-icons/svelte#flag
```

or
```bash
npm install github:iconify/icons-svelte#flag
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/flag/fr-1x1';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/flag/de-1x1';
</script>

<SampleIcon height="1em" />
```
