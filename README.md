## Installation

```bash
npm install gitlab:iconify-icons/svelte#uix
```

or
```bash
npm install github:iconify/icons-svelte#uix
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/uix/account-code';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/uix/electricity';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/uix/dore-bar';
</script>

<SampleIcon style="color: red;" />
```
