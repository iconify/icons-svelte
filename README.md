## Installation

```bash
npm install gitlab:iconify-icons/svelte#devicon-plain
```

or
```bash
npm install github:iconify/icons-svelte#devicon-plain
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/devicon-plain/kotlin';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/devicon-plain/bulma';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/devicon-plain/logstash';
</script>

<SampleIcon style="color: red;" />
```
