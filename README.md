Browse all icons: [preview OOUI on Iconify](https://icon-sets.iconify.design/ooui/)

## Installation

```bash
npm install github:iconify/icons-svelte#ooui
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ooui/search';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ooui/share';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ooui/restore';
</script>

<SampleIcon style="color: red;" />
```
