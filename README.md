**Pinhead Map Icons**

Author: [Quincy Morgan](https://github.com/waysidemapping/pinhead)

License: [CC0](https://creativecommons.org/publicdomain/zero/1.0/)

Browse all icons: [preview Pinhead Map Icons on Iconify](https://icon-sets.iconify.design/pinhead/)

## Installation

```bash
npm install github:iconify/icons-svelte#pinhead
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/pinhead/a-frame-tent';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/pinhead/bird';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/pinhead/boat-on-trailer';
</script>

<SampleIcon style="color: red;" />
```
