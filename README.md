## Installation

```bash
npm install github:iconify/icons-svelte#icon-park-twotone
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/icon-park-twotone/add-one';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/icon-park-twotone/english-mustache';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/icon-park-twotone/basketball-clothes';
</script>

<SampleIcon style="color: red;" />
```
