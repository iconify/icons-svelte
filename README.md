# @iconify-svelte/iconito

**Iconito Food**

Author: [Iconito](https://github.com/iconi-to/free-food)

License: [MIT](https://github.com/iconi-to/free-food/blob/main/LICENSE)

Browse all icons: [preview Iconito Food on Iconify](https://icon-sets.iconify.design/iconito/)

## Installation

```bash
npm install gitlab:iconify-icons/svelte#iconito
```

or
```bash
npm install github:iconify/icons-svelte#iconito
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/iconito/ice-cream';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/iconito/banana';
</script>

<SampleIcon height="1em" />
```
