License: [MIT](https://github.com/samcome/webfont-medical-icons/blob/master/LICENSE)

Browse all icons: [preview Medical Icons on Iconify](https://icon-sets.iconify.design/medical-icon/)

## Installation

```bash
npm install github:iconify/icons-svelte#medical-icon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/medical-icon/i-care-staff-area';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/medical-icon/i-nursery';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/medical-icon/immunizations';
</script>

<SampleIcon style="color: red;" />
```
