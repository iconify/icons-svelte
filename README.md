**Iconaut**

Author: [Iconaut](https://github.com/iconaut-design/icons)

License: [MIT](https://github.com/iconaut-design/icons/blob/main/LICENSE)

Browse all icons: [preview Iconaut on Iconify](https://icon-sets.iconify.design/iconaut/)

## Installation

```bash
npm install gitlab:iconify-icons/svelte#iconaut
```

or
```bash
npm install github:iconify/icons-svelte#iconaut
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/iconaut/award-duo';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/iconaut/play';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/iconaut/bookmark-duo';
</script>

<SampleIcon style="color: red;" />
```
