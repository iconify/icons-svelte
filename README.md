## Installation

```bash
npm install github:iconify/icons-svelte#flagpack
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/flagpack/ci';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/flagpack/gb-ukm';
</script>

<SampleIcon height="1em" />
```
