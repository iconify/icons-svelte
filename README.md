## Installation

```bash
npm install gitlab:iconify-icons/svelte#evicons
```

or
```bash
npm install github:iconify/icons-svelte#evicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/evicons/marker-queue';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/evicons/driving-range';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/evicons/plug-in-hybrid';
</script>

<SampleIcon style="color: red;" />
```
