License: [MIT](https://github.com/dqev/reicon/blob/main/LICENSE)

Browse all icons: [preview Reicon on Iconify](https://icon-sets.iconify.design/reicon/)

## Installation

```bash
npm install github:iconify/icons-svelte#reicon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/reicon/ruler4';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/reicon/cart-add2-filled';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/reicon/search-normal2';
</script>

<SampleIcon style="color: red;" />
```
