## Installation

```bash
npm install gitlab:iconify-icons/svelte#withicons-halloween
```

or
```bash
npm install github:iconify/icons-svelte#withicons-halloween
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/withicons-halloween/home';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/withicons-halloween/search';
</script>

<SampleIcon height="1em" />
```
