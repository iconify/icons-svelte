Browse all icons: [preview Lucide Extended on Iconify](https://icon-sets.iconify.design/lucide-extended/)

## Installation

```bash
npm install gitlab:iconify-icons/svelte#lucide-extended
```

or
```bash
npm install github:iconify/icons-svelte#lucide-extended
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/lucide-extended/circle-check-filled';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/lucide-extended/award-duotone';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/lucide-extended/house-filled';
</script>

<SampleIcon style="color: red;" />
```
