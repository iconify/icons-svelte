# @iconify-svelte/temaki

**Temaki**

Author: [Bryan Housel](https://github.com/rapideditor/temaki)

License: [CC0](https://creativecommons.org/publicdomain/zero/1.0/)

Browse all icons: [preview Temaki on Iconify](https://icon-sets.iconify.design/temaki/)

## Installation

```bash
npm install github:iconify/icons-svelte#temaki
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/temaki/milestone';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/temaki/elevator';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/temaki/storage';
</script>

<SampleIcon style="color: red;" />
```
