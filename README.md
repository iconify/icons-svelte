## Installation

```bash
npm install gitlab:iconify-icons/svelte#thesvg-color
```

or
```bash
npm install github:iconify/icons-svelte#thesvg-color
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/thesvg-color/verizon';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/thesvg-color/mitsubishi';
</script>

<SampleIcon height="1em" />
```
