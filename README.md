## Installation

```bash
npm install gitlab:iconify-icons/svelte#uix-sharp
```

or
```bash
npm install github:iconify/icons-svelte#uix-sharp
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/uix-sharp/account-code';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/uix-sharp/electricity';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/uix-sharp/dore-bar';
</script>

<SampleIcon style="color: red;" />
```
