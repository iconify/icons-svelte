**Devicon**

Author: [konpa](https://github.com/devicons/devicon/tree/master)

License: [MIT](https://github.com/devicons/devicon/blob/master/LICENSE)

Browse all icons: [preview Devicon on Iconify](https://icon-sets.iconify.design/devicon/)

## Installation

```bash
npm install github:iconify/icons-svelte#devicon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/devicon/windows8';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/devicon/tensorflow';
</script>

<SampleIcon height="1em" />
```
