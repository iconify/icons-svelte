Browse all icons: **[Preview Boxicons Brands](https://icon-sets.iconify.design/bxl/)**

## Installation

```bash
npm install github:iconify/icons-svelte#bxl
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/bxl/patreon';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/bxl/adobe';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/bxl/vuejs';
</script>

<SampleIcon style="color: red;" />
```
