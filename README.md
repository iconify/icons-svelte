**Meteor Icons**

Author: [zkreations](https://github.com/zkreations/icons)

License: [MIT](https://github.com/zkreations/icons/blob/main/LICENSE)

Browse all icons: [preview Meteor Icons on Iconify](https://icon-sets.iconify.design/meteor-icons/)

## Installation

```bash
npm install github:iconify/icons-svelte#meteor-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/meteor-icons/droplet';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/meteor-icons/bolt';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/meteor-icons/flipboard';
</script>

<SampleIcon style="color: red;" />
```
