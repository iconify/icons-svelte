Browse all icons: [preview Streamline on Iconify](https://icon-sets.iconify.design/streamline/)

## Installation

```bash
npm install github:iconify/icons-svelte#streamline
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline/sign-hashtag';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline/open-umbrella-solid';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline/graph-bar-increase';
</script>

<SampleIcon style="color: red;" />
```
