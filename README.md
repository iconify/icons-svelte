**Radix Icons**

Author: [WorkOS](https://github.com/radix-ui/icons)

License: [MIT](https://github.com/radix-ui/icons/blob/master/LICENSE)

Browse all icons: [preview Radix Icons on Iconify](https://icon-sets.iconify.design/radix-icons/)

## Installation

```bash
npm install github:iconify/icons-svelte#radix-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/radix-icons/width';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/radix-icons/checkbox';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/radix-icons/code';
</script>

<SampleIcon style="color: red;" />
```
