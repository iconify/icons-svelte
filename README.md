Browse all icons: [preview Pixel free icons on Iconify](https://icon-sets.iconify.design/streamline-pixel/)

## Installation

```bash
npm install github:iconify/icons-svelte#streamline-pixel
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-pixel/shopping-shipping-bag-1';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-pixel/interface-essential-battery';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-pixel/social-rewards-flag';
</script>

<SampleIcon style="color: red;" />
```
