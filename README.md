Browse all icons: [preview Remix Icon on Iconify](https://icon-sets.iconify.design/ri/)

## Installation

```bash
npm install github:iconify/icons-svelte#ri
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ri/lock-2-line';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ri/mark-pen-fill';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ri/moon-line';
</script>

<SampleIcon style="color: red;" />
```
