## Installation

```bash
npm install gitlab:iconify-icons/svelte#cbi
```

or
```bash
npm install github:iconify/icons-svelte#cbi
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/cbi/mitsubishi';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/cbi/espn';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/cbi/rooms-computer';
</script>

<SampleIcon style="color: red;" />
```
