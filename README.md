# @iconify-svelte/fxemoji

Icon set prefix: **fxemoji**

Icon set name: **Firefox OS Emoji**

Author: **Mozilla**

License: **[Apache 2.0](https://mozilla.github.io/fxemoji/LICENSE.md)**

Repository: **https://github.com/mozilla/fxemoji**

Browse all icons: **[Preview Firefox OS Emoji](https://icon-sets.iconify.design/fxemoji/)**

## Installation

```bash
npm install github:iconify/icons-svelte#fxemoji
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/fxemoji/foxweary';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/fxemoji/loveletter';
</script>

<SampleIcon height="1em" />
```
