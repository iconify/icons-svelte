Browse all icons: [preview Jam Icons on Iconify](https://icon-sets.iconify.design/jam/)

## Installation

```bash
npm install github:iconify/icons-svelte#jam
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/jam/chevrons-square-up-right';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/jam/luggage-f';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/jam/rubber';
</script>

<SampleIcon style="color: red;" />
```
