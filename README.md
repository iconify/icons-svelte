**Marketeq**

Author: Marketeq

License: MIT

Browse all icons: [preview Marketeq on Iconify](https://icon-sets.iconify.design/marketeq/)

## Installation

```bash
npm install github:iconify/icons-svelte#marketeq
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/marketeq/mute';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/marketeq/desk-6';
</script>

<SampleIcon height="1em" />
```
