Browse all icons: [preview Quill Icons on Iconify](https://icon-sets.iconify.design/quill/)

## Installation

```bash
npm install github:iconify/icons-svelte#quill
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/quill/collapse';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/quill/desktop';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/quill/moon';
</script>

<SampleIcon style="color: red;" />
```
