# @iconify-svelte/lsicon

**Lsicon**

Author: [Wis Design](https://www.lsicon.com/)

License: [MIT](https://github.com/wisdesignsystem/lsicon/blob/main/LICENSE)

Browse all icons: [preview Lsicon on Iconify](https://icon-sets.iconify.design/lsicon/)

## Installation

```bash
npm install github:iconify/icons-svelte#lsicon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/lsicon/pointer-outline';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/lsicon/column-filled';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/lsicon/vip-outline';
</script>

<SampleIcon style="color: red;" />
```
