Browse all icons: [preview CoreUI Flags on Iconify](https://icon-sets.iconify.design/cif/)

## Installation

```bash
npm install gitlab:iconify-icons/svelte#cif
```

or
```bash
npm install github:iconify/icons-svelte#cif
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/cif/ee';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/cif/ca';
</script>

<SampleIcon height="1em" />
```
