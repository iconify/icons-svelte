## Installation

```bash
npm install gitlab:iconify-icons/svelte#coolicons
```

or
```bash
npm install github:iconify/icons-svelte#coolicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/coolicons/battery-empty-duotone-round';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/coolicons/venus-fill-round';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/coolicons/apple-logo-duocolor-round';
</script>

<SampleIcon style="color: red;" />
```
