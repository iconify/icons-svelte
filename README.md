## Installation

```bash
npm install github:iconify/icons-svelte#vscode-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/vscode-icons/file-type-actionscript2';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/vscode-icons/file-type-json';
</script>

<SampleIcon height="1em" />
```
