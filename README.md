**Stickies color icons**

Browse all icons: [preview Stickies color icons on Iconify](https://icon-sets.iconify.design/streamline-stickies-color/)

## Installation

```bash
npm install github:iconify/icons-svelte#streamline-stickies-color
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-stickies-color/mail';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-stickies-color/love';
</script>

<SampleIcon height="1em" />
```
