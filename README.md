## Installation

```bash
npm install gitlab:iconify-icons/svelte#matita
```

or
```bash
npm install github:iconify/icons-svelte#matita
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/matita/crop';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/matita/activity';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/matita/navigation';
</script>

<SampleIcon style="color: red;" />
```
