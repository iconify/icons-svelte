Browse all icons: [preview ProIcons on Iconify](https://icon-sets.iconify.design/proicons/)

## Installation

```bash
npm install github:iconify/icons-svelte#proicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/proicons/code';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/proicons/checkmark';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/proicons/photo-filter';
</script>

<SampleIcon style="color: red;" />
```
