Browse all icons: [preview Streamline Block on Iconify](https://icon-sets.iconify.design/streamline-block/)

## Installation

```bash
npm install github:iconify/icons-svelte#streamline-block
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-block/other-ui-chat';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-block/content-write';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-block/content-bookmark';
</script>

<SampleIcon style="color: red;" />
```
