**OSM Icons**

Author: [GMGeo](https://github.com/gmgeo/osmic)

License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)

Browse all icons: [preview OSM Icons on Iconify](https://icon-sets.iconify.design/osmic/)

## Installation

```bash
npm install github:iconify/icons-svelte#osmic
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/osmic/post-office-14';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/osmic/elevator-14';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/osmic/pub-14';
</script>

<SampleIcon style="color: red;" />
```
