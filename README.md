Browse all icons: **[Preview Feather Icons](https://icon-sets.iconify.design/feather/)**

## Installation

```bash
npm install github:iconify/icons-svelte#feather
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/feather/check-circle';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/feather/award';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/feather/home';
</script>

<SampleIcon style="color: red;" />
```
