Browse all icons: [preview Pixel Icon on Iconify](https://icon-sets.iconify.design/pixel/)

## Installation

```bash
npm install github:iconify/icons-svelte#pixel
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/pixel/folder-solid';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/pixel/message';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/pixel/bullet-list';
</script>

<SampleIcon style="color: red;" />
```
