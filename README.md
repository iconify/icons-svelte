## Installation

```bash
npm install gitlab:iconify-icons/svelte#carbon
```

or
```bash
npm install github:iconify/icons-svelte#carbon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/carbon/user-certification';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/carbon/humidity';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/carbon/edit-off';
</script>

<SampleIcon style="color: red;" />
```
