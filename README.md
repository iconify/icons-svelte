## Installation

```bash
npm install gitlab:iconify-icons/svelte#xero-emoji
```

or
```bash
npm install github:iconify/icons-svelte#xero-emoji
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/xero-emoji/paperclip';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/xero-emoji/ladder';
</script>

<SampleIcon height="1em" />
```
