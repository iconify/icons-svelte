Browse all icons: [preview Humbleicons on Iconify](https://icon-sets.iconify.design/humbleicons/)

## Installation

```bash
npm install github:iconify/icons-svelte#humbleicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/humbleicons/aid';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/humbleicons/droplet';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/humbleicons/rss';
</script>

<SampleIcon style="color: red;" />
```
