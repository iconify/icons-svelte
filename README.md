## Installation

```bash
npm install github:iconify/icons-svelte#cryptocurrency-color
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/cryptocurrency-color/btc';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/cryptocurrency-color/ltc';
</script>

<SampleIcon height="1em" />
```
