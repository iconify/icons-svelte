Browse all icons: [preview Freehand color icons on Iconify](https://icon-sets.iconify.design/streamline-freehand-color/)

## Installation

```bash
npm install github:iconify/icons-svelte#streamline-freehand-color
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-freehand-color/discount-percent-thin';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-freehand-color/cursor-speed-1';
</script>

<SampleIcon height="1em" />
```
