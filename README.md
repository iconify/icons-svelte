**SVG Logos**

Author: [Gil Barbara](https://github.com/gilbarbara/logos)

License: [CC0](https://raw.githubusercontent.com/gilbarbara/logos/master/LICENSE.txt)

Browse all icons: [preview SVG Logos on Iconify](https://icon-sets.iconify.design/logos/)

## Installation

```bash
npm install github:iconify/icons-svelte#logos
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/logos/npm-icon';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/logos/uikit';
</script>

<SampleIcon height="1em" />
```
