**HeroIcons v1 Outline**

Author: [Refactoring UI Inc](https://github.com/tailwindlabs/heroicons)

License: [MIT](https://github.com/tailwindlabs/heroicons/blob/master/LICENSE)

Browse all icons: [preview HeroIcons v1 Outline on Iconify](https://icon-sets.iconify.design/heroicons-outline/)

## Installation

```bash
npm install github:iconify/icons-svelte#heroicons-outline
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/heroicons-outline/color-swatch';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/heroicons-outline/library';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/heroicons-outline/receipt-refund';
</script>

<SampleIcon style="color: red;" />
```
