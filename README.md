## Installation

```bash
npm install gitlab:iconify-icons/svelte#material-symbols-light
```

or
```bash
npm install github:iconify/icons-svelte#material-symbols-light
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/material-symbols-light/downloading';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/material-symbols-light/privacy-tip';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/material-symbols-light/filter-drama-outline';
</script>

<SampleIcon style="color: red;" />
```
