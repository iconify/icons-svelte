Browse all icons: **[Preview Foundation](https://icon-sets.iconify.design/foundation/)**

## Installation

```bash
npm install github:iconify/icons-svelte#foundation
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/foundation/graph-trend';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/foundation/indent-more';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/foundation/lock';
</script>

<SampleIcon style="color: red;" />
```
