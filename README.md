## Installation

```bash
npm install github:iconify/icons-svelte#emojione-v1
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/emojione-v1/face-savoring-food';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/emojione-v1/panda-face';
</script>

<SampleIcon height="1em" />
```
