**Stash Icons**

Browse all icons: [preview Stash Icons on Iconify](https://icon-sets.iconify.design/stash/)

## Installation

```bash
npm install github:iconify/icons-svelte#stash
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/stash/cloud-solid';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/stash/clock-duotone';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/stash/search-duotone';
</script>

<SampleIcon style="color: red;" />
```
