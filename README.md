Browse all icons: **[Preview Glyphs Poly](https://icon-sets.iconify.design/glyphs-poly/)**

## Installation

```bash
npm install github:iconify/icons-svelte#glyphs-poly
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/glyphs-poly/mouse-2';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/glyphs-poly/object-select';
</script>

<SampleIcon height="1em" />
```
