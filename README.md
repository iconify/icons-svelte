Browse all icons: [preview Majesticons on Iconify](https://icon-sets.iconify.design/majesticons/)

## Installation

```bash
npm install github:iconify/icons-svelte#majesticons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/majesticons/chats-line';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/majesticons/home';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/majesticons/edit-pen-4-line';
</script>

<SampleIcon style="color: red;" />
```
