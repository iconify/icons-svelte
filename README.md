Browse all icons: [preview Noto Emoji (v1) on Iconify](https://icon-sets.iconify.design/noto-v1/)

## Installation

```bash
npm install github:iconify/icons-svelte#noto-v1
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/noto-v1/face-with-open-mouth';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/noto-v1/no-entry';
</script>

<SampleIcon height="1em" />
```
