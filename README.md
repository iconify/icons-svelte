**Prime Icons**

Author: [PrimeTek](https://github.com/primefaces/primeicons)

License: [MIT](https://github.com/primefaces/primeicons/blob/master/LICENSE)

Browse all icons: [preview Prime Icons on Iconify](https://icon-sets.iconify.design/prime/)

## Installation

```bash
npm install github:iconify/icons-svelte#prime
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/prime/book';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/prime/telegram';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/prime/volume-off';
</script>

<SampleIcon style="color: red;" />
```
