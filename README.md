Browse all icons: [preview Nonicons on Iconify](https://icon-sets.iconify.design/nonicons/)

## Installation

```bash
npm install github:iconify/icons-svelte#nonicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/nonicons/kotlin-16';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/nonicons/vue-16';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/nonicons/npm-16';
</script>

<SampleIcon style="color: red;" />
```
