Browse all icons: [preview Memory Icons on Iconify](https://icon-sets.iconify.design/memory/)

## Installation

```bash
npm install github:iconify/icons-svelte#memory
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/memory/chart-bar';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/memory/application';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/memory/message';
</script>

<SampleIcon style="color: red;" />
```
