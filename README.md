# @iconify-svelte/gridicons

**Gridicons**

Author: [Automattic](https://github.com/Automattic/gridicons)

License: [GPL 2.0](https://github.com/Automattic/gridicons/blob/trunk/LICENSE.md)

Browse all icons: [preview Gridicons on Iconify](https://icon-sets.iconify.design/gridicons/)

## Installation

```bash
npm install github:iconify/icons-svelte#gridicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/gridicons/code';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/gridicons/multiple-users';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/gridicons/types';
</script>

<SampleIcon style="color: red;" />
```
