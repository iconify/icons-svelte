## Installation

```bash
npm install gitlab:iconify-icons/svelte#noviair-light
```

or
```bash
npm install github:iconify/icons-svelte#noviair-light
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/noviair-light/navigation';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/noviair-light/skip-forward';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/noviair-light/type';
</script>

<SampleIcon style="color: red;" />
```
