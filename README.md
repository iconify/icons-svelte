Browse all icons: [Preview Glyphs](https://icon-sets.iconify.design/glyphs/)

## Installation

```bash
npm install github:iconify/icons-svelte#glyphs
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/glyphs/mouse-2-bold';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/glyphs/object-select';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/glyphs/comment-1-duo';
</script>

<SampleIcon style="color: red;" />
```
