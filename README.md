**Fluent UI System Icons**

Author: [Microsoft Corporation](https://github.com/microsoft/fluentui-system-icons)

License: [MIT](https://github.com/microsoft/fluentui-system-icons/blob/main/LICENSE)

Browse all icons: [preview Fluent UI System Icons on Iconify](https://icon-sets.iconify.design/fluent/)

## Installation

```bash
npm install github:iconify/icons-svelte#fluent
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/fluent/zoom-out-24-filled';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/fluent/drink-coffee-24-regular';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/fluent/photo-filter-24-regular';
</script>

<SampleIcon style="color: red;" />
```
