Browse all icons: [preview Energy Icons on Iconify](https://icon-sets.iconify.design/energy-icons/)

## Installation

```bash
npm install gitlab:iconify-icons/svelte#energy-icons
```

or
```bash
npm install github:iconify/icons-svelte#energy-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/energy-icons/hex-key-48';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/energy-icons/bookmark-48';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/energy-icons/brackets-48';
</script>

<SampleIcon style="color: red;" />
```
