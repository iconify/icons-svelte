Browse all icons: [preview Flex free icons on Iconify](https://icon-sets.iconify.design/streamline-flex/)

## Installation

```bash
npm install github:iconify/icons-svelte#streamline-flex
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-flex/shield-2';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-flex/number-sign';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-flex/heart';
</script>

<SampleIcon style="color: red;" />
```
