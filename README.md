**IconOven**

License: MIT

Browse all icons: [preview IconOven on Iconify](https://icon-sets.iconify.design/iconoven/)

## Installation

```bash
npm install gitlab:iconify-icons/svelte#iconoven
```

or
```bash
npm install github:iconify/icons-svelte#iconoven
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/iconoven/bell';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/iconoven/home';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/iconoven/credit-card';
</script>

<SampleIcon style="color: red;" />
```
