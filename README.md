## Installation

```bash
npm install gitlab:iconify-icons/svelte#solar
```

or
```bash
npm install github:iconify/icons-svelte#solar
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/solar/magnifier-zoom-out-broken';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/solar/armchair-2-bold-duotone';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/solar/traffic-economy-line-duotone';
</script>

<SampleIcon style="color: red;" />
```
