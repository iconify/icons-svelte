Browse all icons: [preview Pullo Icons on Iconify](https://icon-sets.iconify.design/pullo/)

## Installation

```bash
npm install gitlab:iconify-icons/svelte#pullo
```

or
```bash
npm install github:iconify/icons-svelte#pullo
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/pullo/file-check';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/pullo/turtle-fill';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/pullo/chart-area-duotone';
</script>

<SampleIcon style="color: red;" />
```
