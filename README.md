Browse all icons: [preview Teenyicons on Iconify](https://icon-sets.iconify.design/teenyicons/)

## Installation

```bash
npm install github:iconify/icons-svelte#teenyicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/teenyicons/face-id-solid';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/teenyicons/user-outline';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/teenyicons/page-break-outline';
</script>

<SampleIcon style="color: red;" />
```
