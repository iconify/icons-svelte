**Gravity UI Icons**

Author: [YANDEX LLC](https://github.com/gravity-ui/icons/)

License: [MIT](https://github.com/gravity-ui/icons/blob/main/LICENSE)

Browse all icons: [preview Gravity UI Icons on Iconify](https://icon-sets.iconify.design/gravity-ui/)

## Installation

```bash
npm install github:iconify/icons-svelte#gravity-ui
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/gravity-ui/magnifier';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/gravity-ui/bookmark-fill';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/gravity-ui/display';
</script>

<SampleIcon style="color: red;" />
```
