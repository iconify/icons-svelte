# @iconify-svelte/gcp

Icon set prefix: **gcp**

Icon set name: **Google Cloud Icons**

Author: **Google Cloud**

License: **[Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0)**

Browse all icons: **[Preview Google Cloud Icons](https://icon-sets.iconify.design/gcp/)**

## Installation

```bash
npm install github:iconify/icons-svelte#gcp
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/gcp/filestore';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/gcp/trace';
</script>

<SampleIcon height="1em" />
```
