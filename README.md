**Pixelarticons**

License: [MIT](https://github.com/halfmage/pixelarticons/blob/master/LICENSE)

Browse all icons: [preview Pixelarticons on Iconify](https://icon-sets.iconify.design/pixelarticons/)

## Installation

```bash
npm install github:iconify/icons-svelte#pixelarticons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/pixelarticons/home';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/pixelarticons/arrows-horizontal';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/pixelarticons/heart';
</script>

<SampleIcon style="color: red;" />
```
