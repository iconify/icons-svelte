Icon set prefix: **dashicons**

Icon set name: **Dashicons**

Author: **WordPress**

License: **[GPL](https://github.com/WordPress/dashicons/blob/master/gpl.txt)**

Repository: **https://github.com/WordPress/dashicons**

Browse all icons: **[Preview Dashicons](https://icon-sets.iconify.design/dashicons/)**

## Installation

```bash
npm install github:iconify/icons-svelte#dashicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/dashicons/shortcode';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/dashicons/businessperson';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/dashicons/editor-expand';
</script>

<SampleIcon style="color: red;" />
```
