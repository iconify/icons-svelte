**Siemens Industrial Experience Icons**

Author: [Siemens AG](https://github.com/siemens/ix-icons)

License: [MIT](https://github.com/siemens/ix-icons/blob/main/LICENSE.md)

Browse all icons: [preview Siemens Industrial Experience Icons on Iconify](https://icon-sets.iconify.design/ix/)

## Installation

```bash
npm install github:iconify/icons-svelte#ix
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ix/notification-filled';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ix/home-filled';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ix/panel-ipc';
</script>

<SampleIcon style="color: red;" />
```
