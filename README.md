Browse all icons: [preview Zondicons on Iconify](https://icon-sets.iconify.design/zondicons/)

## Installation

```bash
npm install github:iconify/icons-svelte#zondicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/zondicons/copy';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/zondicons/hand-stop';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/zondicons/mouse';
</script>

<SampleIcon style="color: red;" />
```
