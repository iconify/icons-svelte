Browse all icons: [preview Weather Icons on Iconify](https://icon-sets.iconify.design/wi/)

## Installation

```bash
npm install github:iconify/icons-svelte#wi
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/wi/day-hail';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/wi/barometer';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/wi/day-windy';
</script>

<SampleIcon style="color: red;" />
```
