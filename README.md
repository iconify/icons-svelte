Browse all icons: [preview Sharp free icons on Iconify](https://icon-sets.iconify.design/streamline-sharp/)

## Installation

```bash
npm install github:iconify/icons-svelte#streamline-sharp
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-sharp/home-1';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-sharp/paperclip-2';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-sharp/new-folder';
</script>

<SampleIcon style="color: red;" />
```
