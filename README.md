## Installation

```bash
npm install github:iconify/icons-svelte#covid
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/covid/social-distancing-correct-2';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/covid/personal-hygiene-clean-toothpaste';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/covid/vaccine-protection-medicine-pill';
</script>

<SampleIcon style="color: red;" />
```
