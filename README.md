Browse all icons: [preview Material Design Icons on Iconify](https://icon-sets.iconify.design/mdi/)

## Installation

```bash
npm install github:iconify/icons-svelte#mdi
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/mdi/account-check';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/mdi/bell-alert-outline';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/mdi/calendar-edit';
</script>

<SampleIcon style="color: red;" />
```
