## Installation

```bash
npm install gitlab:iconify-icons/svelte#lucide
```

or
```bash
npm install github:iconify/icons-svelte#lucide
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/lucide/circle-check';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/lucide/award';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/lucide/house';
</script>

<SampleIcon style="color: red;" />
```
