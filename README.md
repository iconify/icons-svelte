## Installation

```bash
npm install gitlab:iconify-icons/svelte#tabler-flags
```

or
```bash
npm install github:iconify/icons-svelte#tabler-flags
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/tabler-flags/aland-islands';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/tabler-flags/japan';
</script>

<SampleIcon height="1em" />
```
