## Installation

```bash
npm install github:iconify/icons-svelte#circle-flags
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/circle-flags/ee';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/circle-flags/klingon';
</script>

<SampleIcon height="1em" />
```
