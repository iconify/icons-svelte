## Installation

```bash
npm install github:iconify/icons-svelte#qlementine-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/qlementine-icons/windows-16';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/qlementine-icons/check-tick-small-16';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/qlementine-icons/speaker-0-16';
</script>

<SampleIcon style="color: red;" />
```
