## Installation

```bash
npm install github:iconify/icons-svelte#vs
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/vs/edit-page';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/vs/kakao-square';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/vs/person';
</script>

<SampleIcon style="color: red;" />
```
