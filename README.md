## Installation

```bash
npm install gitlab:iconify-icons/svelte#withicons
```

or
```bash
npm install github:iconify/icons-svelte#withicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/withicons/home';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/withicons/search-duo';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/withicons/settings-solid';
</script>

<SampleIcon style="color: red;" />
```
