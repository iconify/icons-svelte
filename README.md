## Installation

```bash
npm install github:iconify/icons-svelte#iconmind
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/iconmind/agent-outline-regular';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/iconmind/vector-database-duotone-thin';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/iconmind/stub-tool-outline-bold';
</script>

<SampleIcon style="color: red;" />
```
