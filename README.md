Browse all icons: **[Preview FormKit Icons](https://icon-sets.iconify.design/formkit/)**

## Installation

```bash
npm install github:iconify/icons-svelte#formkit
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/formkit/checkbox';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/formkit/reorder';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/formkit/submit';
</script>

<SampleIcon style="color: red;" />
```
