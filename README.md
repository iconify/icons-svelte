Browse all icons: [preview with icons Skeuo on Iconify](https://icon-sets.iconify.design/withicons-skeuo/)

## Installation

```bash
npm install gitlab:iconify-icons/svelte#withicons-skeuo
```

or
```bash
npm install github:iconify/icons-svelte#withicons-skeuo
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/withicons-skeuo/home';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/withicons-skeuo/search';
</script>

<SampleIcon height="1em" />
```
