Browse all icons: [preview Cyber color icons on Iconify](https://icon-sets.iconify.design/streamline-cyber-color/)

## Installation

```bash
npm install github:iconify/icons-svelte#streamline-cyber-color
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-cyber-color/shopping-basket-3';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-cyber-color/command-2';
</script>

<SampleIcon height="1em" />
```
