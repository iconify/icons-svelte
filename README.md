# @iconify-svelte/twemoji

**Twitter Emoji**

Author: [Twitter](https://github.com/jdecked/twemoji)

License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

Browse all icons: [preview Twitter Emoji on Iconify](https://icon-sets.iconify.design/twemoji/)

## Installation

```bash
npm install github:iconify/icons-svelte#twemoji
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/twemoji/anguished-face';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/twemoji/duck';
</script>

<SampleIcon height="1em" />
```
