**UnJS Logos**

Author: [UnJS](https://github.com/unjs)

License: Apache 2.0

Browse all icons: [preview UnJS Logos on Iconify](https://icon-sets.iconify.design/unjs/)

## Installation

```bash
npm install github:iconify/icons-svelte#unjs
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/unjs/nitro';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/unjs/jiti';
</script>

<SampleIcon height="1em" />
```
