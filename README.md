Browse all icons: [preview Open Iconic on Iconify](https://icon-sets.iconify.design/oi/)

## Installation

```bash
npm install github:iconify/icons-svelte#oi
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/oi/bug';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/oi/bullhorn';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/oi/chat';
</script>

<SampleIcon style="color: red;" />
```
