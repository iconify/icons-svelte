# @iconify-svelte/tdesign

**TDesign Icons**

Author: [TDesign](https://github.com/Tencent/tdesign-icons)

License: [MIT](https://github.com/Tencent/tdesign-icons/blob/main/LICENSE)

Browse all icons: [preview TDesign Icons on Iconify](https://icon-sets.iconify.design/tdesign/)

## Installation

```bash
npm install github:iconify/icons-svelte#tdesign
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/tdesign/activity';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/tdesign/doge';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/tdesign/dam';
</script>

<SampleIcon style="color: red;" />
```
