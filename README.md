Browse all icons: **[Preview Element Plus](https://icon-sets.iconify.design/ep/)**

## Installation

```bash
npm install github:iconify/icons-svelte#ep
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ep/home-filled';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ep/partly-cloudy';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ep/avatar';
</script>

<SampleIcon style="color: red;" />
```
