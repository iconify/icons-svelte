# @iconify-svelte/meteocons

**Meteocons**

Author: [Bas Milius](https://github.com/basmilius/weather-icons)

License: [MIT](https://github.com/basmilius/weather-icons/blob/dev/LICENSE)

Browse all icons: [preview Meteocons on Iconify](https://icon-sets.iconify.design/meteocons/)

## Installation

```bash
npm install github:iconify/icons-svelte#meteocons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/meteocons/hurricane-fill';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/meteocons/sunrise-fill';
</script>

<SampleIcon height="1em" />
```
