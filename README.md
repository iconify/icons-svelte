## Installation

```bash
npm install gitlab:iconify-icons/svelte#selfhst
```

or
```bash
npm install github:iconify/icons-svelte#selfhst
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/selfhst/salt';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/selfhst/adobe';
</script>

<SampleIcon height="1em" />
```
