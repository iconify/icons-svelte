**Line Awesome**

License: [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0)

Browse all icons: [preview Line Awesome on Iconify](https://icon-sets.iconify.design/la/)

## Installation

```bash
npm install github:iconify/icons-svelte#la
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/la/archive-solid';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/la/female-solid';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/la/check-circle';
</script>

<SampleIcon style="color: red;" />
```
