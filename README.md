## Installation

```bash
npm install gitlab:iconify-icons/svelte#uix-solid
```

or
```bash
npm install github:iconify/icons-svelte#uix-solid
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/uix-solid/account-code';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/uix-solid/electricity';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/uix-solid/dore-bar';
</script>

<SampleIcon style="color: red;" />
```
