Browse all icons: [preview Akar Icons on Iconify](https://icon-sets.iconify.design/akar-icons/)

## Installation

```bash
npm install github:iconify/icons-svelte#akar-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/akar-icons/paper';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/akar-icons/pencil';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/akar-icons/location';
</script>

<SampleIcon style="color: red;" />
```
