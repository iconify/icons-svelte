**Simple line icons**

Author: [Sabbir Ahmed](https://github.com/thesabbir/simple-line-icons)

License: [MIT](https://github.com/thesabbir/simple-line-icons/blob/master/LICENSE.md)

Browse all icons: [preview Simple line icons on Iconify](https://icon-sets.iconify.design/simple-line-icons/)

## Installation

```bash
npm install github:iconify/icons-svelte#simple-line-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/simple-line-icons/bubbles';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/simple-line-icons/camrecorder';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/simple-line-icons/cloud-upload';
</script>

<SampleIcon style="color: red;" />
```
