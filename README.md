## Installation

```bash
npm install github:iconify/icons-svelte#file-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/file-icons/adobe';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/file-icons/chartjs';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/file-icons/dom';
</script>

<SampleIcon style="color: red;" />
```
