Browse all icons: [preview SidekickIcons on Iconify](https://icon-sets.iconify.design/sidekickicons/)

## Installation

```bash
npm install github:iconify/icons-svelte#sidekickicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/sidekickicons/crown';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/sidekickicons/blockquote';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/sidekickicons/compass';
</script>

<SampleIcon style="color: red;" />
```
