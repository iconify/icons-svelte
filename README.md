# @iconify-svelte/ph

**Phosphor**

Author: [Phosphor Icons](https://github.com/phosphor-icons/core)

License: [MIT](https://github.com/phosphor-icons/core/blob/main/LICENSE)

Browse all icons: [preview Phosphor on Iconify](https://icon-sets.iconify.design/ph/)

## Installation

```bash
npm install github:iconify/icons-svelte#ph
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ph/folder-open-duotone';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ph/check-square-offset-thin';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/ph/pencil-line-fill';
</script>

<SampleIcon style="color: red;" />
```
