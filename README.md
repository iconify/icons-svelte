## Installation

```bash
npm install gitlab:iconify-icons/svelte#codicon
```

or
```bash
npm install github:iconify/icons-svelte#codicon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/codicon/account';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/codicon/bell-dot';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/codicon/new-file';
</script>

<SampleIcon style="color: red;" />
```
