**Skill Icons**

Author: [tandpfun](https://github.com/tandpfun/skill-icons)

License: [MIT](https://github.com/tandpfun/skill-icons/blob/main/LICENSE)

Browse all icons: [preview Skill Icons on Iconify](https://icon-sets.iconify.design/skill-icons/)

## Installation

```bash
npm install github:iconify/icons-svelte#skill-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/skill-icons/markdown-light';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/skill-icons/vuejs-dark';
</script>

<SampleIcon height="1em" />
```
