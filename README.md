## Installation

```bash
npm install gitlab:iconify-icons/svelte#noviair
```

or
```bash
npm install github:iconify/icons-svelte#noviair
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/noviair/wand';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/noviair/menu';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/noviair/summit';
</script>

<SampleIcon style="color: red;" />
```
