# @iconify-svelte/healthicons

**Health Icons**

Author: [Resolve to Save Lives](https://github.com/resolvetosavelives/healthicons)

License: [MIT](https://github.com/resolvetosavelives/healthicons/blob/main/LICENSE)

Browse all icons: [preview Health Icons on Iconify](https://icon-sets.iconify.design/healthicons/)

## Installation

```bash
npm install github:iconify/icons-svelte#healthicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/healthicons/cold-chain';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/healthicons/emergency-post';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/healthicons/asthma-outline';
</script>

<SampleIcon style="color: red;" />
```
