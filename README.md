Browse all icons: [preview Memes on Iconify](https://icon-sets.iconify.design/streamline-memes/)

## Installation

```bash
npm install gitlab:iconify-icons/svelte#streamline-memes
```

or
```bash
npm install github:iconify/icons-svelte#streamline-memes
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-memes/angry-face';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-memes/pop-cat';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-memes/pop-cat';
</script>

<SampleIcon style="color: red;" />
```
