## Installation

```bash
npm install github:iconify/icons-svelte#fluent-emoji-flat
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/fluent-emoji-flat/avocado';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/fluent-emoji-flat/ticket';
</script>

<SampleIcon height="1em" />
```
