License: [MIT](https://github.com/oreo-design/doodle-icons/blob/main/LICENSE)

Browse all icons: [preview Oreo Doodle Icons on Iconify](https://icon-sets.iconify.design/doodle-icons/)

## Installation

```bash
npm install gitlab:iconify-icons/svelte#doodle-icons
```

or
```bash
npm install github:iconify/icons-svelte#doodle-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/doodle-icons/heart';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/doodle-icons/home';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/doodle-icons/bell';
</script>

<SampleIcon style="color: red;" />
```
