**Huge Icons**

Author: [Hugeicons](https://icon-sets.iconify.design/icon-sets/hugeicons/)

License: MIT

Browse all icons: [preview Huge Icons on Iconify](https://icon-sets.iconify.design/hugeicons/)

## Installation

```bash
npm install github:iconify/icons-svelte#hugeicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/hugeicons/analytics-up';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/hugeicons/android';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/hugeicons/search-02';
</script>

<SampleIcon style="color: red;" />
```
