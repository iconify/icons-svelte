# @iconify-svelte/raphael

**Raphael**

Author: [Dmitry Baranovskiy](https://github.com/dmitrybaranovskiy/raphael)

License: MIT

Browse all icons: [preview Raphael on Iconify](https://icon-sets.iconify.design/raphael/)

## Installation

```bash
npm install github:iconify/icons-svelte#raphael
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/raphael/home';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/raphael/cloud';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/raphael/parent';
</script>

<SampleIcon style="color: red;" />
```
