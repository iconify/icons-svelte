Browse all icons: [preview Material Design Light on Iconify](https://icon-sets.iconify.design/mdi-light/)

## Installation

```bash
npm install github:iconify/icons-svelte#mdi-light
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/mdi-light/cart';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/mdi-light/bell';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/mdi-light/login';
</script>

<SampleIcon style="color: red;" />
```
