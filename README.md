Repository: **https://github.com/twbs/icons**

Browse all icons: **[Preview Bootstrap Icons](https://icon-sets.iconify.design/bi/)**

## Installation

```bash
npm install github:iconify/icons-svelte#bi
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/bi/graph-up';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/bi/card-image';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/bi/code-slash';
</script>

<SampleIcon style="color: red;" />
```
