**Vaadin Icons**

Author: [Vaadin](https://github.com/vaadin/web-components)

Browse all icons: [preview Vaadin Icons on Iconify](https://icon-sets.iconify.design/vaadin/)

## Installation

```bash
npm install github:iconify/icons-svelte#vaadin
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/vaadin/area-select';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/vaadin/file-picture';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/vaadin/plus-circle-o';
</script>

<SampleIcon style="color: red;" />
```
