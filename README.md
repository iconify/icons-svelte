# @iconify-svelte/icons8

**Icons8 Windows 10 Icons**

Author: [Icons8](https://github.com/icons8/windows-10-icons)

License: MIT

Browse all icons: [preview Icons8 Windows 10 Icons on Iconify](https://icon-sets.iconify.design/icons8/)

## Installation

```bash
npm install github:iconify/icons-svelte#icons8
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/icons8/checked';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/icons8/create-new';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/icons8/group';
</script>

<SampleIcon style="color: red;" />
```
