# @iconify-svelte/maki

**Maki**

Author: [Mapbox](https://github.com/mapbox/maki)

License: [CC0](https://creativecommons.org/publicdomain/zero/1.0/)

Browse all icons: [preview Maki on Iconify](https://icon-sets.iconify.design/maki/)

## Installation

```bash
npm install github:iconify/icons-svelte#maki
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/maki/entrance-alt1';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/maki/clothing-store';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/maki/grocery';
</script>

<SampleIcon style="color: red;" />
```
