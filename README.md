## Installation

```bash
npm install gitlab:iconify-icons/svelte#andrsrxn
```

or
```bash
npm install github:iconify/icons-svelte#andrsrxn
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/andrsrxn/agent';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/andrsrxn/hashtag';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/andrsrxn/box';
</script>

<SampleIcon style="color: red;" />
```
