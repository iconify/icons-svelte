Browse all icons: [preview Lineicons on Iconify](https://icon-sets.iconify.design/lineicons/)

## Installation

```bash
npm install github:iconify/icons-svelte#lineicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/lineicons/check';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/lineicons/vuejs';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/lineicons/star-fat';
</script>

<SampleIcon style="color: red;" />
```
