Browse all icons: [preview Griddy Icons on Iconify](https://icon-sets.iconify.design/griddy-icons/)

## Installation

```bash
npm install github:iconify/icons-svelte#griddy-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/griddy-icons/annotation';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/griddy-icons/twitch-filled';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/griddy-icons/chart-bar-up-alt';
</script>

<SampleIcon style="color: red;" />
```
