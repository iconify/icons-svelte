# @iconify-svelte/wpf

**Icons8 Windows 8 Icons**

Author: [Icons8](https://github.com/icons8/WPF-UI-Framework)

License: MIT

Browse all icons: [preview Icons8 Windows 8 Icons on Iconify](https://icon-sets.iconify.design/wpf/)

## Installation

```bash
npm install github:iconify/icons-svelte#wpf
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/wpf/check-file';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/wpf/add-image';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/wpf/geo-fence';
</script>

<SampleIcon style="color: red;" />
```
