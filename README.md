## Installation

```bash
npm install github:iconify/icons-svelte#fluent-emoji-high-contrast
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/fluent-emoji-high-contrast/avocado';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/fluent-emoji-high-contrast/ticket';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/fluent-emoji-high-contrast/straight-ruler';
</script>

<SampleIcon style="color: red;" />
```
