Browse all icons: [preview Nimbus on Iconify](https://icon-sets.iconify.design/nimbus/)

## Installation

```bash
npm install github:iconify/icons-svelte#nimbus
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/nimbus/barcode';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/nimbus/mail';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/nimbus/calendar';
</script>

<SampleIcon style="color: red;" />
```
