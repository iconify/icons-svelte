# @iconify-svelte/heroicons

**HeroIcons**

Author: [Refactoring UI Inc](https://github.com/tailwindlabs/heroicons)

License: [MIT](https://github.com/tailwindlabs/heroicons/blob/master/LICENSE)

Browse all icons: [preview HeroIcons on Iconify](https://icon-sets.iconify.design/heroicons/)

## Installation

```bash
npm install github:iconify/icons-svelte#heroicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/heroicons/camera';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/heroicons/building-library';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/heroicons/receipt-refund';
</script>

<SampleIcon style="color: red;" />
```
