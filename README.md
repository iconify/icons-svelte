Browse all icons: [preview Unicons Monochrome on Iconify](https://icon-sets.iconify.design/uim/)

## Installation

```bash
npm install github:iconify/icons-svelte#uim
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/uim/airplay';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/uim/circle-layer';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/uim/lock-access';
</script>

<SampleIcon style="color: red;" />
```
