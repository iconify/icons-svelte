Browse all icons: [preview Streamline color on Iconify](https://icon-sets.iconify.design/streamline-color/)

## Installation

```bash
npm install github:iconify/icons-svelte#streamline-color
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-color/graph';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/streamline-color/pie-chart-flat';
</script>

<SampleIcon height="1em" />
```
