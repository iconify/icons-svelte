Browse all icons: [preview Kubernetes Icons on Iconify](https://icon-sets.iconify.design/k8s/)

## Installation

```bash
npm install github:iconify/icons-svelte#k8s
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/k8s/deployment';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/k8s/pod';
</script>

<SampleIcon height="1em" />
```
