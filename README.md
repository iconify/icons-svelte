Browse all icons: [preview System UIcons on Iconify](https://icon-sets.iconify.design/system-uicons/)

## Installation

```bash
npm install github:iconify/icons-svelte#system-uicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/system-uicons/bell';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/system-uicons/message-writing';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/system-uicons/write';
</script>

<SampleIcon style="color: red;" />
```
