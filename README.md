**WeUI Icon**

Browse all icons: [preview WeUI Icon on Iconify](https://icon-sets.iconify.design/weui/)

## Installation

```bash
npm install github:iconify/icons-svelte#weui
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/svelte/).

Few usage examples:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/weui/search-outlined';
</script>

<SampleIcon />
```

To resize icon, set `width` and/or `height` parameters:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/weui/clip-filled';
</script>

<SampleIcon height="1em" />
```

To change icon color, use style:

```svelte
<script lang="ts">
import SampleIcon from '@iconify-svelte/weui/done-filled';
</script>

<SampleIcon style="color: red;" />
```
